PROSTE API DO SCRAPOWANIA PLANU ZAJĘĆ NA COLLEGIUM WITELONA

Plan zajęć na uczelni ssie, jest nie czytelny, nie dostosowany do urządzeń mobilych itp.

Zrobiłem te api pod aplikację mobilną, która ma na celu ułatwienie korzystania z planu zajęć.

Uruchamianie
```
 python -m venv .venv
 source .venv/bin/Activate.ps1
 pip install -r requirements.txt
 python -m main.py (server uvicorn sam się uruchomi)
```

Uruchamianie testów
```
python -m pytest
```
